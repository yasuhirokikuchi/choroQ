# choroQ（寸止め）

机の上でミニカーを引っ張り、爆弾の手前で止める DxLib 製ミニゲームです。

## 必要環境

- Visual Studio 2022（C++ デスクトップ開発ワークロード）
- [DxLib](https://dxlib.xsrv.jp/)（Visual Studio 用）


## 操作

| キー | 内容 |
|------|------|
| E | メニューからゲーム開始 |
| Z | 終了 |
| ← → | 車種選択（3種） |
| Space 長押し | 引っ張る（パワー蓄積） |
| Space 離す | 発射 |
| R | リスタート |
| Esc | メニューへ戻る |

## ソース構成

- `Main.cpp` … エントリ / DxLib 初期化（ウィンドウモード）
- `SceneMgr` … メニュー ↔ ゲーム切替
- `Menu` … タイトル画面
- `Game` … 寸止め本編
